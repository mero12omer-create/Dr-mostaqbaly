# منصة دكتور مستقبلي

## التشغيل على Windows

افتح Terminal داخل مجلد المشروع ثم نفّذ:

```bash
npm install
npm start
```

بعدها افتح المتصفح على:

```text
http://localhost:3000
```

## إعداد الذكاء الاصطناعي

انسخ `.env.example` إلى `.env` وضع مفتاح AI جديداً في `AI_API_KEY`. الإعداد الافتراضي المرفق مناسب لمزود متوافق مع OpenAI API مثل Groq:

```env
AI_API_URL=https://api.groq.com/openai/v1/chat/completions
AI_MODEL=llama-3.3-70b-versatile
```

لا تضع ملف `.env` داخل الحزمة التي سترسلها لأي شخص، ولا تشارك مفتاح AI في المحادثات أو لقطات الشاشة.

## البريد وOTP

حتى يعمل التسجيل الكامل، اضبط `EMAIL_USER` و`EMAIL_PASS` في `.env`. كلمة مرور Gmail يجب أن تكون App Password، وليس كلمة مرور الحساب الأساسية. عند عدم ضبط البريد، سيرجع الخادم خطأ واضحاً ولن يعرض رمز OTP في الاستجابة.

## OCR للـPDF المصوّر

قراءة PDF النصي لا تحتاج OCR. أما PDF المصوّر فيحتاج وجود `pdftoppm` وTesseract مع اللغتين العربية والإنجليزية داخل PATH. في Windows ثبّت Poppler وTesseract، ثم أعد فتح Terminal قبل تشغيل المشروع.

## أهم الوظائف

تسجيل الطالب يحفظ جلسة آمنة بتوكن، والامتحان يصحح على الخادم ويضيف النقاط مرة واحدة فقط. الألقاب هي: طالب جديد، طالب مجتهد عند 100 نقطة، طالب متميز عند 300، طالب متفوق عند 600، ودكتور مستقبلي عند 1000 نقطة. الشهادات تُنشأ عند الوصول إلى مراحل الألقاب وتظهر في الملف الشخصي ويمكن فتحها للطباعة.

المذكرات لا تظهر للطلاب إلا بعد اعتماد الأدمن. لكل مذكرة اسم صاحب، فرع، مجموعة، ومادة. صفحة الامتحانات وصفحة المذكرات ولوحة الأدمن تدعم عام وأزهر، ومجموعات الأزهر الشرعية والعربية والثقافية.

## ملاحظات أمان

الخادم يعرض صفحات الواجهة المسموح بها فقط، ولا يعرض قاعدة البيانات أو `.env` أو كود الخادم عبر المتصفح.

## قاعدة البيانات والملفات (Supabase)

المشروع بقى يستخدم Supabase بدل SQLite المحلي:

- **قاعدة البيانات**: PostgreSQL عبر متغير `DATABASE_URL` (من Supabase → Database → Connection string).
- **ملفات المذكرات**: تتخزن في Supabase Storage (Bucket خاص/Private)، وتُعرض للطالب برابط مؤقت (Signed URL) صالح لمدة ساعة فقط.

اضبط المتغيرات دي في `.env` قبل التشغيل: `DATABASE_URL`، `SUPABASE_URL`، `SUPABASE_SERVICE_KEY`، `SUPABASE_BUCKET`.

النسخ الاحتياطي بقى مسؤولية Supabase (بيعمل نسخ احتياطي تلقائي)، ومفيش داعي لعمل backup يدوي لملف database.db لأنه بقى غير مستخدم.
